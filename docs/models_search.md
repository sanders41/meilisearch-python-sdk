## Search Models

These are the models used by the search methods. `search` returns a `SearchResults` object,
`facet_search` returns a `FacetSearchResults` object, and `search_similar_documents` returns a
`SimilarSearchResults` object. `Hybrid`, `Personalize`, and the `Federation` models are passed
into the search methods to control how the search is run.
